# 🎮 Jogo de Adivinhação

Um jogo interativo e divertido onde você tenta adivinhar um número secreto em apenas 3 tentativas!

## 📋 Descrição

Este é um jogo de adivinhação desenvolvido em HTML5 e JavaScript puro. O objetivo é simples: adivinhe um número aleatório entre 1 e 10 antes que suas tentativas acabem. O jogo fornece feedback visual com emojis para tornar a experiência mais agradável.

## ✨ Funcionalidades

- 🎯 **Jogo Interativo**: Adivinhe números entre 1 e 10
- 🔢 **3 Tentativas**: Você tem no máximo 3 tentativas para acertar
- 💬 **Feedback em Tempo Real**: Mensagens claras indicando se acertou ou errou
- 🎉 **Celebração**: Feedback visual com emojis ao acertar ou perder
- 🔄 **Jogar Novamente**: Reinicie o jogo a qualquer momento
- 🎨 **Design Responsivo**: Interface moderna com gradiente azul atraente
- 📱 **Interface Intuitiva**: Fácil de usar para todos os públicos

## 🚀 Como Usar

1. **Abra o arquivo** `Jogo de Adivinhação-01.html` em seu navegador
2. **Digite um número** entre 1 e 10 no campo de entrada
3. **Clique no botão** "Adivinhar" para fazer seu palpite
4. **Receba feedback** sobre seu palpite
5. **Tente novamente** ou **"Jogar Novamente"** para recomeçar

### Instruções Passo a Passo:
- Insira um número válido (1-10)
- Você verá uma mensagem indicando se acertou, errou ou se perdeu
- O contador de tentativas será atualizado
- Ao acertar ou perder, clique em "Jogar Novamente" para uma nova partida

## 🎮 Como Funciona

### Lógica do Jogo:
1. Um número aleatório entre 1 e 10 é gerado quando a página carrega
2. O jogador faz palpites e recebe feedback
3. O número de tentativas diminui a cada palpite inválido
4. O jogo termina quando:
   - O jogador acerta o número (vitória)
   - O jogador fica sem tentativas (derrota)
